# SURadar

Prova de conceito do Radar de Futuros da Seguros Unimed (v5).

- `index.html`: a POC, arquivo único, abre direto no navegador (ou pela raw.githack: https://raw.githack.com/EGLBRA/temp/main/SURadar/index.html).
- 41 temas de futuro em nove dimensões STEEPLEDI, cor por linha de produto, anéis por horizonte (2027, 2030, 2035, 2050) ou postura (Agir, Preparar, Observar).
- Páginas: Radar, Linha do tempo, Explorar, Relações (com matriz de correlações), Cruzamentos e jogadas, Cenários 2035, Macrotendências, Impacto x Horizonte, Indicadores de mercado, Índice.
- Conteúdo: primeira varredura de fontes públicas, classificação proposta para calibração com as áreas de produto.
